# ⚡ TechFlow - Plataforma de Automação No-Code

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)

## 📌 Sobre o projeto

O **Flowfy** é uma plataforma de automação de processos empresariais criada para permitir que empresas automatizem tarefas repetitivas sem precisar de conhecimento em programação.

A plataforma permite conectar ferramentas utilizadas no dia a dia, como planilhas, e-mails, formulários, CRMs, ERPs, bancos de dados e APIs, criando fluxos automatizados através de uma interface visual baseada em blocos.

A ideia é transformar processos manuais em automações simples, reduzindo tempo operacional e aumentando a produtividade das equipes.

---

## 🎯 Problema

Muitas empresas ainda gastam horas realizando tarefas repetitivas, como:

- Copiar dados de formulários para planilhas;
- Enviar mensagens individuais para clientes;
- Atualizar informações em diferentes sistemas;
- Gerar relatórios manualmente;
- Repassar informações entre setores.

Além disso, muitas soluções de automação existentes possuem interfaces complexas para usuários sem conhecimento técnico.

# 🚀 Funcionalidades

## Automações visuais

- Criação de workflows utilizando blocos;
- Sistema de gatilhos e ações;
- Conexão entre etapas através de fluxo visual;
- Teste e execução das automações.
